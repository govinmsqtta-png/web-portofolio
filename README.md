# Govindha Muskitta — Portfolio Website

Website portfolio statis pribadi milik **Govindha Muskitta**, mahasiswa Ilmu Komputer dari Kota Ambon. Dibangun menggunakan HTML5, CSS3, dan JavaScript murni tanpa framework.

## Fitur

- **Animated Background** — Partikel mengambang yang terhubung dengan garis, dirender menggunakan HTML5 Canvas API
- **Dark / Light Mode** — Toggle tema terang dan gelap tanpa library tambahan
- **Typing Effect** — Animasi teks berketik otomatis di section Hero
- **Smooth Scroll** — Navigasi halus antar section dengan offset navbar
- **Scroll Reveal** — Elemen fade-in + slide-up saat masuk viewport menggunakan IntersectionObserver
- **Skill Progress Bars** — Bar animasi yang terisi saat section Skills terlihat
- **Responsive Design** — Tampilan adaptif untuk mobile, tablet, dan desktop
- **Hamburger Menu** — Menu navigasi mobile dengan animasi slide
- **Form Validasi** — Form kontak dengan validasi client-side (nama, email, pesan)
- **Back to Top** — Tombol kembali ke atas yang muncul saat scroll ke bawah
- **Aurora Hero Background** — Gradien animasi pada section Hero

## Cara Menjalankan

Tidak memerlukan instalasi apapun. Cukup buka file langsung di browser:

```
Klik dua kali pada file: indexhtml.html
```

Atau gunakan ekstensi **Live Server** di VS Code untuk development:

1. Install ekstensi Live Server di VS Code
2. Klik kanan `indexhtml.html`
3. Pilih **Open with Live Server**
